# Pol Sex Crimes

A brutalist two-column research website and its source report.

- `politician_sex_crime_research.md` — sourced research report
- `public/` — static website source
- `server.js` — local preview server
- `build.mjs` — static build copy step

The website is organized with Democrats on the left and Republicans on the right on desktop, with a responsive stacked layout on mobile.
